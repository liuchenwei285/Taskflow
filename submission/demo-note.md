# 高等数学 · 第三章 微分中值定理与导数应用（课堂笔记）

## 3.1 微分中值定理
- 罗尔定理：若 f 在 [a,b] 连续、(a,b) 可导且 f(a)=f(b)，则存在 ξ∈(a,b) 使 f'(ξ)=0。
- 拉格朗日中值定理：f(b)-f(a)=f'(ξ)(b-a)。它是罗尔定理去掉端点相等条件后的推广。
- 柯西中值定理：[f(b)-f(a)]/[g(b)-g(a)] = f'(ξ)/g'(ξ)，要求 g'(x)≠0。

## 3.2 洛必达法则
- 适用 0/0 与 ∞/∞ 型；使用前必须验证型别，且导数之比的极限存在（或为无穷）。
- 例：lim(x→0) (x - sin x)/x^3 = 1/6。连续三次洛必达或泰勒展开均可。
- 常见错误：把 lim (1+1/x)^x 直接套洛必达；应先取对数化为 0·∞ 型。

## 3.3 泰勒公式
- f(x) = f(x0) + f'(x0)(x-x0) + f''(x0)(x-x0)^2/2! + … + Rn(x)。
- 麦克劳林展开：e^x = 1 + x + x^2/2! + …；sin x = x - x^3/3! + x^5/5! - …。
- 佩亚诺余项用于求极限，拉格朗日余项用于估计误差。

## 3.4 单调性与极值
- f'(x)>0 则单调增；驻点不一定是极值点（如 y=x^3 在 x=0）。
- 第一充分条件看导数变号；第二充分条件看 f''(x0) 的符号。

## 3.5 凹凸性与拐点
- f''(x)>0 为凹（向上弯）；拐点处凹凸性改变，需检查 f'' 变号而非仅 f''=0。

## 本章易错点
1. 中值定理的 ξ 是"存在"而非"任意"，证明题不能把 ξ 当已知量代入。
2. 洛必达失效不代表原极限不存在，应换泰勒或夹逼。
3. 极值点与驻点、不可导点三者关系要分清。
