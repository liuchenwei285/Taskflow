# 学习工作台 + 试卷库 · 使用与验证说明

> 面向验证 Agent 的简明说明。项目：Taskflow 单文件 Web App。

## 1. 这是什么
Taskflow 的学习工作台：上传学习资料 → 解析 → AI 出题 → 公式渲染 → 导出 / 存入试卷库。只做学习相关；创建任务前必须确认。

## 2. 入口与文件
- 导航（5 项）：**学习工作台（首屏）** / 任务 / 统计 / **试卷库** / 设置
- 主文件：`Taskflow/task-timer-app.html`（单文件，内联 JS/CSS + 内联 KaTeX/html2canvas 载荷）
- 依赖源：`Taskflow/vendor/`（KaTeX 0.16.11、html2canvas 1.4.1 及其 MIT 许可），由 `tools/build-vendor-payload.js` 内联
- 副本（必须逐字节一致）：`Taskflow/site/index.html`、`Taskflow/android/app/src/main/assets/index.html`
- 测试：`cd Taskflow && npm test`

## 3. 前置条件（AI）
二选一：
1. **浏览器直连**：设置 → AI 服务 → 直连模式，填 DeepSeek Key。Key 只存页面内存，**填完不要刷新**。
2. **服务端**：开通 Qoder Sites 后端并配置环境变量 `DEEPSEEK_API_KEY`。出题走 `POST <前缀>/ai/study`（`functions/handler.ts` 的 `study()`），密钥只在服务端读取，响应只回题目；当前线上后端未开通（接口返回 409 `sites_gateway_supabase_not_ready`），因此线上暂时只能走直连模式。
3. 前端顺序：先探测 `/health`，后端可用就走 `/ai/study`；后端 404/405（路由未部署）且本地有 Key 时回落直连；两者都没有则报「AI 服务未连接」`#BE`，**不发任何上游请求、不伪造试卷**。

上传的资料需解析到「已就绪」才能出题。

## 4. 主流程（复现步骤）
1. 学习工作台 点回形针，选择或拖入资料（可多选）。
2. 文件卡片显示 文件名 / 大小 / 解析状态；可「预览」「下载」。
3. 输入自然语言，例如：`根据这个笔记出一套试卷，导出 PDF`。
4. **发送前确认卡片**（不是「将发送」提示文本）：列出资料文件名、正文字数、你的原话、题量，并说明除这些内容外不发送任务库/账号信息。题量以你句子里写的数字为准（`出 5 道题` → 卡片显示 5 道、实际也只发 5 道；没写则用面板默认 10 道，上限 20）。两个按钮：「确认发送」/「取消」；**取消 = 一个请求都不发**，也不产生试卷与任务面板。
5. 确认后出现「AI 正在思考 · n/4」气泡，按阶段推进：**读取资料 → 生成题目 → 校验 → 生成 PDF**；成功、失败、超时、取消都会落到明确终态，气泡不会一直转圈。
6. 生成试卷卡片：题量、题型分布、预计时长；题干/选项/答案与解析均渲染公式。
7. 紧随其后是**真实 PDF 文件卡片**（`1 页 · 68.9 KB · 含答案与解析`）：「预览」在浮层里显示 PDF 的每一页位图，「下载 PDF」下载同一份字节。
8. 卡片可导出 **PDF / PNG / Markdown / JSON / CSV**，并自动存入「试卷库」；试卷库同样提供这五种导出。
9. **试卷与 PDF 出来之后**才出现「任务草稿」面板（待确认）：标题为「完成《试卷名》练习卷」，预计时长取试卷估算分钟数；点「确认创建」才写入任务库，点「取消」只留试卷。面板永远排在试卷卡之后，且**不会自动建任务**。
10. 出题失败给出**分类错误卡片**：一句原因 + 一句可操作建议 + 短码（如 `#NET`、`#TMO`、`#KEY`）+ 上游原文（已脱敏）。可重试类别带正式「重试」按钮，重试自动保留原要求与已上传资料，**无需重新上传、无需重新输入**。
11. 连续失败 3 次后重试按钮停用，并提示按建议处理（补密钥 / 充值 / 减小题量）后重新发送。
12. 失败后直接输入「继续 / 重试 / 然后呢 / go on」等短指令 = 重跑同一件事（出题），不会被当成新建任务。
13. 有出卷意图但资料还没解析就绪：只提示先上传资料，**零 AI 请求、零任务草稿**。
14. 英文同样识别出卷意图（`Generate 5 questions from this note`、`Make a test paper…`、`Make another quiz`），确认卡片、阶段气泡、错误卡片均为英文；普通任务请求（`Remind me to submit the homework by Friday`）仍走草稿路径。

## 5. 数据与存储（验证时勿破坏）
- `taskflow.tasks.v1`：任务库，**不修改**（仅通过 taskId 等关联）。
- 学习模块独立版本化键：资料元数据 `taskflow.study.documents.v1`、试卷集 `taskflow.study.sets.v1`。
- 资料去重指纹：每条资料带 `sha256`（`sha256:` + 十六进制；WebView 无 `crypto.subtle` 时回落 `fnv1a:`），去重键为「文件名 + 字节数 + 指纹」。
- 对话：独立 `CHAT_KEY`（与任务库分离）。
- 原件：**IndexedDB** `taskflow-study-v1` → store `files`（大文件不写 LocalStorage）。
- 删除资料/试卷不影响已创建任务。

## 6. 依赖（KaTeX / html2canvas 已内联，离线可用）
| 库 | 版本 | 用途 | 加载方式 | 许可 |
|---|---|---|---|---|
| KaTeX | 0.16.11 | 公式渲染 | **应用内联**（`#tfVendor` gzip+base64 → blob / data URI），失败才回落 CDN | MIT |
| html2canvas | 1.4.1 | PDF/PNG 栅格化 | **应用内联**，同上 | MIT |
| pdfjs-dist | 3.11.174 | PDF 文本/页码 | 仍走 CDN（数 MB，未内联） | Apache-2.0 |
| tesseract.js | 5.1.1 | 图片 OCR | 仍走 CDN（含语言包，未内联） | Apache-2.0 |

- 内联载荷由 `node tools/build-vendor-payload.js` 从 `vendor/` 生成，写入 `task-timer-app.html` 的 `<!-- VENDOR:BEGIN/END -->` 区块；源文件被解析为 JS/CSS（gzip+base64）与 woff2 字体（base64 data URI）。
- 运行期状态可在控制台读 `window.__vendorState`：`local` / `cdn` / `failed`。
- 两条通道都失败时**不静默降级**：公式保留原始 LaTeX 文本，并弹出「依赖组件加载失败」横幅给出可操作指引。
- DOCX/PPTX/XLSX 用原生 `DecompressionStream`+`DOMParser`，无第三方库。

## 7. 关键实现位置（审阅用）
- `chatSetCard`：试卷卡片渲染（含公式）
- `studyRenderMath`：`$...$` 行内 / `$$...$$` 块级 → KaTeX
- `ensureKatex` / `ensureH2C`：按需加载，先内联后 CDN，两败则告警
- `vendorPayload` / `vendorRunScript` / `loadVendorKatex`：内联资源解压器
- `studyGenerate` / `studyPlan` / `studyConfirmResolve`：出卷入口 → 确认卡片（取消零请求）→ `studyRun`
- `studyRun` / `studyCall`：四阶段推进（`studyStagePaint`）→ 优先服务端 `/ai/study`，未部署时回落直连 → 校验 → 存库 → PDF 卡片
- `studyParseJson` / `studySalvageQuestions`：围栏剥离 → 平衡括号 → 逐题抢救；`finish_reason==='length'` 归入「输出被截断」
- `studyArtifactAdd` / `studyBuildPdfPages` / `chatArtifactCard`：真实 PDF 字节 + 每页位图，卡片提供预览与下载
- `aiErrInfo` / `aiErrText` / `chatAddErr` / `chatErrCard` / `chatRetryNode`：错误分类、短码、建议与重试次数上限（`CHAT_RETRY_MAX=3`）
- `studyIngest` / `studyDocKey` / `studyDigestBytes` / `studyFindDuplicate`：入库去重（文件名 + 字节数 + SHA-256 内容指纹）
- `studyBackfillDigests`：为历史资料补算指纹，保证刷新后仍去重
- `renderSetCanvas` / `buildSetPdfBlob` / `buildSetPngBlob`：同一份排版 → 图片版 PDF 或 PNG
- `studyLibraryRender`：试卷库列表 / PDF·PNG·MD·JSON·CSV 导出 / 删除
- `functions/handler.ts`：`harnessScope`（学习范围判定）、`HARNESS_TOOLS`（工具白名单）、`/ai/chat`

## 8. 支持格式与限制
- 支持：PNG/JPG/JPEG/WEBP、PDF、DOCX、PPTX、TXT/MD、XLSX、CSV
- 不支持：DOC/PPT（旧二进制，提示另存为 DOCX/PPTX）
- PDF 为**图片版**：中文/公式正确，文字不可选中

## 9. 安全与边界
- 文件头（magic bytes）校验真实格式；改扩展名的伪装文件被拒
- 限额：单文件 20MB、20 份、合计 80MB、解析超时 20s、解压上限 12MB
- Key 不写入 HTML / LocalStorage / APK
- 服务端意图判定：明显非学习请求拒绝且不调用上游；工具白名单仅 8 个学习工具；资料内容按不可信数据处理（防提示注入）

## 11. 未实现（勿误判为 Bug）
- DOCX 导出；练习卷与答案分开；仅题目导出
- 单题编辑 / 单题重生成；知识点清单独立展示
- 试卷库搜索 / 筛选 / 复制 / 批量导出
- 试卷与任务只做「一次提议」级关联：草稿标题/时长来自试卷，创建后不再双向同步（改试卷不会改任务）
- 流式输出（后端未支持）；后端当前 disabled（409）
- pdfjs-dist / tesseract.js 仍依赖 CDN：离线时 PDF 文本抽取与图片 OCR 不可用（公式渲染与导出不受影响）
- 中文搜索为子串匹配（不分词、不匹配拼音），大小写不敏感；拼音/分词检索未实现

## 12. 本地运行与测试
```bash
cd Taskflow
npm install                 # 首次
npm test                    # 13 套全量（e2e-study 231 项 / e2e-taskflow 183 项 / e2e-view 41 项 / e2e-notify 33 项 / tools/test-ai-handler 131 项）
node tools/build-vendor-payload.js   # 改了 vendor/ 后重新内联
node tools/sync-i18n.js              # 改了 i18n/en.json 后重新注入
PORT=3000 npm test                   # 指定端口；8899 被系统拒绝绑定时自动临时改用 18899 并打印提示
```
单套件：先 `npm run serve`（8899），再 `node e2e-study.js`；如需指向别的端口，
`TASKFLOW_URL=http://127.0.0.1:3000/ node e2e-view.js`。
无 Key 时用路由桩验证出题/导出：拦截 `**/chat/completions` 返回
`{"choices":[{"message":{"content":"<题目JSON字符串>"}}]}`，并用 `window.__aiTest.setKey('sk-test')` 注入内存 Key；
`e2e-study.js` 第 14 节用「首次 503、二次 200」的桩覆盖失败与重试，任何测试都不需要真实 API Key。

**真实连通验收（需要你自己把密钥放进 shell 环境，切勿写进仓库文件）**：
```bash
DEEPSEEK_API_KEY=你的密钥 node --experimental-strip-types dev/function-local.ts   # 终端 A
node tools/serve.js                                                               # 终端 B
node dev/live-study-run.mjs                                                       # 终端 C：真实出题 + 真实 PDF，17 项
```
`dev/live-study-run.mjs` 不打任何桩：它断言页面直连 `api.deepseek.com` 的请求数为 0、出题只走 `/ai/study`、
真实题目含 KaTeX 公式、下载的 PDF 以 `%PDF-` 开头且页数与卡片一致，并把样本存到 `dev/live-paper.pdf`。
跑完记得关掉带密钥的进程，再执行 `npm test`（否则回归套件会打到真实账户产生费用）。

## 13. 错误提示对照（每类一句原因 + 一句建议 + 短码）
| 类别 | 中文提示（原因） | 短码 | 建议（卡片第二行） | 重试按钮 |
|---|---|---|---|---|
| 网络异常 | 网络异常，请检查连接后重试 | `#NET` | 检查本机网络或代理；公司/校园网可能屏蔽外网 API | 有 |
| 后端未部署/接口不存在 | AI 服务未连接：本站未开通后端代理 | `#BE` | 开通 Sites Functions 并部署 `functions/handler.ts`，或直连填 Key | 无（先改配置） |
| 服务端缺密钥 | 服务端尚未配置 DeepSeek API Key | `#KEY` | 在 Sites Secret / 函数环境变量配置 | 有（配好即可再试） |
| 密钥无效 | AI 服务认证失败（服务端密钥无效） | `#AUTH` | 到 DeepSeek 控制台核对密钥 | 无 |
| 余额不足 | DeepSeek 账户余额不足 | `#BAL` | 到控制台充值 | 无 |
| 请求超时 | 请求超时，请重试 | `#TMO` | 点重试或把题量改小 | 有（自动减题量） |
| 频率限制 | 请求过于频繁 / DeepSeek 正在限流 | `#RATE` | 稍等一分钟再试 | 有 |
| 额度用完 | 今日 AI 调用额度已用完 | `#QUOTA` | 明天再试或改用直连 | 无 |
| 非法 JSON / 校验失败 | AI 返回的内容无法解析 | `#JSON` | 点重试；仍失败就把题型题量写具体 | 有 |
| 输出被截断 | 模型输出被截断，题目没写完 | `#TRUNC` | 点重试会自动减少题量 | 有（自动减题量） |
| 模型名不被接受 | 模型名不被接受（可能已下线） | `#MODEL` | 用「测试连接」列出可用模型再选 | 有 |
| 资料不足以出题 | 资料内容不足以出题 | `#DATA` | 换更完整的资料或减小题量 | 有 |
| 未知错误 | AI 调用失败（未知错误） | `#UNK` | 把括号里的短码发给排查的人 | 有 |

- 卡片第三段是上游原文（`HTTP 503 · Service Unavailable`），已脱敏（密钥形如 `sk-***`）且不含堆栈。
- 其他非 AI 提示：「依赖组件加载失败」= 内联副本与 CDN 都没加载成功，公式按原始文本显示、导出会失败；「解析失败：…」= 文件损坏/加密/格式不符；「原件不可用，可能已被清理」= IndexedDB 原件缺失。
