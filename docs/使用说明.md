# Taskflow 使用说明

> 一句话：把学习/工作任务记下来 → 拆开 → 专注做完 → 自动统计。需要出题时，用自然语言把学习资料丢给「学习工作台」。
> 数据全部存在你自己的浏览器里，不上传服务器（只有 AI 功能会把内容发给你配置的大模型服务）。

---

## 1. 怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 在线体验 | 浏览器打开 <https://taskflow-app-3qo4c3iuyvd.qoder.zone> | 公开访问，无需注册登录 |
| 本地单文件 | 双击 `task-timer-app.html`（或 `site/index.html`） | 整个应用就这一个文件，离线可用，除 AI 外不联网 |
| 手机 | 装 APK，或用手机浏览器打开上面的在线地址 | 窄屏会自动换成底部导航 + 侧拉抽屉 |

**注意：数据是跟着「浏览器 + 地址」走的。** 本地文件、`localhost`、在线站点是三份互相独立的数据；换浏览器、换设备、清理浏览器数据都会看不到原数据。要迁移请看第 10 节。

## 2. 界面地图

宽屏（≥900px）左侧是常驻侧栏，里面是四块主页面，设置入口在侧栏右下角：

| 入口 | 干什么 |
| --- | --- |
| **学习工作台** | 打开时的默认页。用一句话安排学习、上传资料出试卷 |
| **任务** | 任务列表 + 专注计时，应用的主战场 |
| **统计** | 今日/累计专注、任务计数、近 7 天趋势、科目与优先级分布 |
| **试卷库** | 学习工作台生成过的试卷，可预览、下载、删除 |
| **设置**（侧栏右下角齿轮 / 底部导航最后一项） | 主题、语言、AI 服务、数据备份、通知 |

侧栏还包含：**新会话**按钮、**历史会话**列表（按「今天 / 昨天 / 过去 7 天 / 更早」分组）、**···（会话管理）**、**收起侧栏**、**深浅色切换**。

- 屏幕宽度 900–1023px 时侧栏自动收起成 64px 图标栏，点顶部收起按钮可以展开。
- 窄于 900px 时侧栏收进抽屉，点左上角菜单按钮呼出。

## 3. 三分钟上手

1. **记一件事**：任务页点「+ 新建任务」（或按 `N`）。只填标题就能保存。
2. **开始做**：卡片上点「开始」，进入倒计时；切到别的标签页、刷新页面都不会中断计时。
3. **做完**：点「完成」，任务进「已完成」，这段时间计入统计。
4. **想偷懒**：点「暂停」，随时「继续」；如果过了截止时间任务变成「已到期」，卡片上会出现「延期」（+1 小时）和「修改截止」。

## 4. 任务：新建与字段

「新建任务」弹窗有两个页签：**手动填写** / **AI 生成**（AI 页签需要先在设置里配好密钥，见第 7.5 节）。

手动填写可设置的项：

| 字段 | 说明 |
| --- | --- |
| 任务标题 | 必填 |
| 备注（可选） | 搜索时会一起匹配 |
| 优先级 | 高 / 中 / 低 |
| 时间模式 | **任务**（可设预计时长 + 截止时间）/ **番茄钟**（专注与休息交替、多轮推进） |
| 预计时长 | 小时 + 分钟，用来估算和排程 |
| 日期 / 时刻 | 截止时间 |

编辑器底部还有两个开关：**保存后立即开始计时**（默认关，关掉就是存进「待开始」，由你手动开始）和**到期时提示音 + 系统通知**（每个任务单独控制）。

保存后任务默认进入 **「待开始」**，因为它还没有开始专注。

任务页顶部的分段控件用来切「全部 / 进行中 / 已完成」，列表内部再按 **待开始、已到期、已完成** 分组展示；正在计时中的任务只会出现在它该在的那一组，不会重复。

## 5. 专注执行

- **开始 / 暂停 / 继续 / 完成**：都在任务卡片上。多个任务可以同时计时，互不影响；暂停或完成时会把这一段结算进实际用时。
- 计时用的是**时间戳**（本段起点会落盘，不会被重置）：刷新页面、切到别的标签页、甚至关掉页面重开，只要没点暂停，流逝的时间照样算进去。
- **「更多操作」**（卡片上的菜单按钮）里是：**编辑、重置计时、删除**。
- **到期了怎么办**：任务到期会**自动暂停**，卡片上不再给「开始」按钮，而是给 **延期**（截止时间 +1 小时）和**修改截止**（打开编辑）。处理完任务就回到「待开始」，由你决定什么时候继续。实测：一个到期 10 分钟的任务点「延期」后，截止时间变成 50 分钟后，卡片恢复成正常任务的样子。
- **来得及吗**：非番茄任务如果同时设了预计时长和截止时间，剩余时间不够做完时会提示「距截止只剩 X，但预计还需 Y」，可以选择「仍然开始」或者去改截止时间。
- **做错了能反悔**：点「完成」后，提示条上有「撤销」，原状态原样还原。
- **番茄模式**：在编辑器里把时间模式选成「番茄钟」，可设专注（5–120 分钟）、短休息（1–30）、长休息（5–60）、轮数（1–8），也有 15 / 25 / 45 分钟的预设。休息中可以「跳过休息」，一轮结束可以「再来一轮」。
- **键盘**：`N` 新建任务；`空格` 打开排序菜单；`Esc` 关闭弹窗。

## 6. 查找与整理

- **搜索框**：按标题和备注实时过滤，中文输入法组合输入过程中不会误触发。
- **排序**：标题右侧的排序按钮（或按 `空格`），可选多种排序方式。
- **分组**：按状态/优先级等维度分组显示。
- **仅看状态**：筛选面板里可只看某个状态，「清除筛选」恢复。

## 7. 学习工作台（AI）与试卷库

### 7.1 一句话安排

在输入框里直接写，比如：

- 「周五晚八点前写完高数作业，大概两小时，很重要」
- 「三天内复习完线代第 3 章，每天 1 小时」
- 「明天上午 10 点交英语作文，需要 90 分钟」

也可以点输入框上方的三条示例引导语直接填进去。

**首次发送前需要勾选数据发送同意项**（「我了解内容将发送至服务端处理，仅用于生成任务草稿」），没勾会提示「请先勾选数据发送同意项」，勾选状态会记住。

**发送前会先出确认卡片**：确认才会真正请求 AI，取消则一个请求都不发。请求过程中有 4 段「AI 正在思考」状态提示，可以中途取消。

### 7.2 上传资料出试卷

点输入框**左侧的回形针**上传学习材料，支持：
`.png .jpg .jpeg .webp .pdf .doc .docx .ppt .pptx .txt .md .csv .xlsx`

流程：上传 → 解析知识点 → AI 出题 → 生成试卷 PDF → 自动存进「试卷库」。
PDF 会以文件卡片出现在对话里，可以**预览**和**下载**。
出完试卷后应用会问「要不要为它建一个练习任务？」——**确认后才创建任务**，不需要直接取消即可。

### 7.3 会话管理

- **新会话**：开一段干净的对话。
- **自动命名**：新会话默认叫「新会话」，收到你的第一句话后自动取前 15 个字当标题。
- **重命名 / 删除**：鼠标悬停在会话上，右侧浮出时间和两个图标按钮（重命名、删除）。重命名按 `Enter` 或点别处保存，`Esc` 取消。
- **清空全部**：侧栏「···」→「清空全部」，需要**二次确认**；它会删掉所有历史会话记录（留一个空白会话），**已创建的任务不受影响**。
- **触屏**：没有悬停，所以当前会话那一行会常显操作按钮；右键 / 长按任意会话行也能呼出「删除会话」菜单。
- **键盘**：`Tab` 进入列表，`↑` `↓` `Home` `End` 在会话间移动，`Enter` 打开。

### 7.4 试卷库

来源只有一个：在学习工作台出题成功后自动「存入试卷库」。这里可以打开预览、下载，或删除某一份（删除试卷不影响由它创建的任务）。

### 7.5 要让 AI 能用，得先解决密钥

**当前线上站点的后端代理没有开通**（函数网关返回 `sites_gateway_supabase_not_ready`），所以默认的服务端模式会报「AI 服务未连接」。两条可行路径：

| 方式 | 怎么配 | 密钥存在哪 |
| --- | --- | --- |
| **浏览器直连（现在线上能用）** | 设置 → AI 服务 → 在「DeepSeek API Key」里填密钥并保存，密钥方式选「浏览器直连」 | **只在当前页面内存里，刷新即失效**，不写本地存储、不写代码 |
| **服务端变量（推荐，需先开通后端）** | 在 Qoder Sites 开通 Functions 并部署 `functions/handler.ts`，把密钥配成服务端环境变量，密钥方式选「服务端变量」 | 服务端，前端永远拿不到 |

配置里还能自定义 Provider（显示名称、Provider ID、API 地址、协议 OpenAI Chat Completions / Anthropic Messages、模型目录）和切换模型（内置 `deepseek-flash` / `deepseek-v4-pro`），改完可以点「测试连接」验证。

AI 出错时的提示都是「原因 + 下一步 + 短码」的形式（例如 `BE` 表示后端未连接、`KEY` 表示密钥问题），按提示处理即可；部分错误可以直接点「重试」。

## 8. 统计

**统计页**：今日专注 / 累计专注；全部任务 / 计时中 / 已到期 / 已完成四个计数；近 7 天趋势图（「专注 / 完成」两个页签切换）；近 12 周专注热力图；完成率；按优先级分布；按科目分布。

- **科目是自动识别的**：没有单独的科目字段，应用按**任务标题里的关键词**归类，识别桶为：高数、线代、英语、物化生、政史地、编程，识别不出就算「其他」。所以标题里带上科目名（高数 / 线代 / 英语 / 物理 / 历史 / 算法……）分布图才会准。
- 已经删掉的任务，它产生的专注时长**仍然算数**，此时近 7 天图上会标「含已删除任务」。

## 9. 设置页有什么

设置页顶部就有一张**「使用帮助」卡片**，把计时和到期规则讲清楚了——遇到行为上的疑问先看它，它和应用是同一份代码维护的。往下依次是：

| 区块 | 内容 |
| --- | --- |
| **AI 服务** | 接口配置、模型、密钥（详见第 7.5 节） |
| **外观** | 深浅色主题、**自定义主题色**（选一个强调色，按钮/进度条/选中与焦点态都跟随，「恢复默认」还原）、**动态取色**（跟随系统壁纸生成强调色，背景保持中性） |
| **语言** | 中文 / English，即时生效 |
| 提醒 | 系统通知的**授权状态**与入口（未授权时自动只用页面内提醒） |
| **数据** | 导出备份 / 导入备份 / 清空全部数据，本机存储用量 |

**关于提醒的两条规则**（容易误会，单独说明）：

- **到达截止时间**：页面内一定会弹提醒；开了开关并授权系统通知，还会响铃 + 发系统通知。浏览器拒绝授权时自动退化为只用页面内提醒，功能不丢；误拒了可以去浏览器地址栏的站点设置里恢复。
- **预计时长用完**：只显示「超时」，**不会自动把任务标记完成**，什么时候算做完由你决定。

**主题选择会记住**，刷新后保持；深浅色切换带转场动画。

## 10. 数据、备份与迁移

所有数据都在浏览器的 `localStorage` 里，对应的键：

| 键 | 内容 |
| --- | --- |
| `taskflow.tasks.v1` | 任务与专注记录 |
| `taskflow.prefs.v1` | 主题、语言、侧栏折叠等偏好 |
| 会话记录键 | 学习工作台的对话历史 |
| `taskflow.ai.v1` | AI 服务配置（**不含明文密钥**） |
| `taskflow.backup.v1` | **导入前自动留的一份当前数据快照**（只有最近 1 份，纯保险） |

**导出**：设置 → 数据 → 「导出备份」（下载一个 JSON）。
**导入**：设置 → 数据 → 「导入备份」（选择之前导出的 JSON）。导入前会先自动给当前数据留一份快照，然后问你：

- **确定 = 合并**：按任务 id 去重，同 id 保留较新的那个；
- **取消 = 覆盖**：用备份里的内容整体替换当前任务列表。
**清空全部数据**：同一张卡片里的红色项，会清掉本机全部任务与记录，操作前请先导出。

建议：换设备、重装系统、清理浏览器数据之前先导出一次。导出的 JSON 就是完整备份，含任务和专注历史。

## 11. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 打开是空的，之前的任务不见了 | 换了浏览器/地址/设备，或清理了浏览器数据。用设置 → 数据 → 导入恢复备份 |
| AI 报「AI 服务未连接 / BE」 | 线上后端代理未开通。按第 7.5 节填自己的密钥走直连；每次刷新都要重填 |
| 直连填了密钥，刷新后又要填 | 设计如此，密钥故意不落盘，避免留在本机存储里 |
| 计时数字和预期不符 | 计时基于时间戳，页面关着也算时间；如果是暂停状态则不计时 |
| 收不到到期提醒 | 系统通知未授权。设置里点授权；被浏览器拒绝就只用页面内提醒 |
| 英文界面有漏翻译 | 反馈具体位置。所有界面文案都走同一份词典 `i18n/en.json` |
| 试卷 PDF 公式显示异常 | 数学公式用内联的 KaTeX 渲染，离线也能显示；若某份异常请把原对话内容反馈出来 |

## 12. 已知边界（不是 Bug）

- AI 出题/解析依赖外部大模型服务，没有可用密钥时这两项不可用；任务、计时、统计、试卷库浏览等全部功能不依赖网络。
- 单设备单浏览器，**没有云端同步**：多设备请用导出/导入。
- 在线站点当前未开通后端代理，服务端 AI 模式需要先在 Qoder Sites 开通 Functions 并配置密钥。
- 数据只存在本机：浏览器「清除站点数据」会一并删除，且无法找回（除非有导出的 JSON）。
